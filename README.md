# Deadeye

Русскоязычный помощник для стандартного Deadlock: ручной снимок матча, детерминированный тактический приоритет и публичная историческая статистика. Демо — вымышленные значения ситуации, явно помеченные в интерфейсе даже после редактирования. Кнопка «Новый ручной снимок» очищает все поля и переключает в ручной режим. Это не live-данные. Опционально доступен публичный снимок матча с задержкой. Приложение не читает память, не внедряется в игру и не автоматизирует действия.

## Windows x64: запуск и сборка

Для разработки нужны Node.js, Rust с MSVC toolchain, Visual Studio Build Tools (Desktop development with C++) и WebView2 Runtime. На Windows 10/11 WebView2 обычно уже установлен; установщик Tauri при необходимости загрузит runtime. Выполните `npm ci`, затем `npm run tauri dev`. Для установщика: `npm run tauri build -- --target x86_64-pc-windows-msvc`. NSIS `.exe` находится в `src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/`. GitHub Actions собирает и сохраняет его как артефакт без подписи и публикации. Windows-сборка здесь не проверена.

Для HUD используйте оконный или безрамочный оконный режим игры: в эксклюзивном полноэкранном режиме HUD может быть невидим. В Windows сочетание **Ctrl+Shift+F8** показывает и скрывает HUD без явного перевода фокуса. Статус регистрации виден в главном окне; если сочетание занято, освободите его в другой программе и нажмите «Повторить регистрацию». HUD в Windows не получает фокус и не показывается в панели задач; если сочетание не работает, кнопка «Открыть HUD» и крестик остаются запасным вариантом. Перетаскивание и работа поверх игры зависят от режима игры и оконной среды. Флажок «Пропускать клики через HUD» позволяет нажимать на игру сквозь HUD. Пока он включён, HUD нельзя перетащить или закрыть мышью: снимите флажок в главном окне, чтобы вернуть управление. После перезапуска режим отключён. Закрытие главного окна завершает приложение и HUD.

## Разработка на Linux

Требуются Node.js, Rust и системные зависимости Tauri 2 (в Linux в том числе WebKitGTK 4.1). В каталоге проекта:

```sh
npm install
npm test
npm run tauri dev
# Проверка Rust-бэкенда на Linux:
cargo check --manifest-path src-tauri/Cargo.toml
```

`npm run dev` открывает только браузерный интерфейс; отдельный HUD работает в Tauri. Снимок сохраняется локально. Нажмите «Открыть HUD», перетаскивайте его за шапку или тело, скрывайте крестиком и повторно открывайте из основного окна. HUD синхронизируется через localStorage; ни один снимок не передаётся API.

На Linux управление расположением, поверх остальных окон и перетаскивание зависят от оконного менеджера. Wayland-композитор может игнорировать always-on-top или ограничения позиционирования; в X11 поведение также зависит от WM. Эксклюзивный полноэкранный режим игры может перекрывать HUD; попробуйте оконный/безрамочный режим. Горячая клавиша и пропуск кликов доступны только в Windows.

## Данные и ограничения

Герои и предметы загружаются из `/v1/assets/heroes?only_active=true` и `/v1/assets/items`; статистика — из `/v1/analytics/hero-stats` и `/v1/analytics/item-stats?hero_ids=…&min_matches=100` на https://api.deadlock-api.com. Используются только предметы типа upgrade; цена берётся из поля `cost` API. Выводится доля побед и число матчей; топ сортируется по доле побед при минимуме 100 матчей, без поправки на смещение выборки. Поздние покупки, выбор героя и другие факторы влияют на корреляцию: она не доказывает, что предмет вызвал победу. API не знает текущий инвентарь или состояние игры. При недоступности сети ручной режим и демо продолжают работать; статистика не подменяется вымышленной. Модель рекомендаций находится в `src/model.ts` и не зависит от источника снимка.

## Публичный снимок матча (не live)

Необязательно: введите числовой Steam3 account ID или SteamID64 и нажмите «Подключить». Только после этого ID передаётся `api.deadlock-api.com` через публичный `/v1/matches/active?account_id=…`; ручные сведения не отправляются. Источник охватывает лишь стандартные матчи, перечисленные в игровом Watch (топ-200), а не все текущие игры. Ответ API кэшируется (max-age до 120 секунд, возможна дополнительная задержка stale-while-revalidate до 120 секунд); показанное время — время получения, не время состояния матча. Обновление ограничено интервалом 130 секунд; ручная кнопка использует тот же интервал. Автоматические запросы прекращаются при отключении или выборе демо; после перезапуска необходимо подключиться снова.

Герой и души команд берутся из снимка; живые, объекты, личные души и время не получаются из этого источника и остаются неизвестными до ручного ввода. Ручные наблюдения относятся к конкретному матчу: при потере источника они сохраняются, но считаются непроверенными; проверьте их. Герой и экономика при первой потере сбрасываются. При смене матча или отключении поля сбрасываются; восстановление источника после потери также начинает новый снимок. В этом случае можно продолжить вручную или загрузить демо. Старые результаты запросов после отключения игнорируются. Пустое поле или «Неизвестно» — не ноль и не отсутствие угрозы; помощник ограничивает рекомендации при недостаточных данных. Пока получен публичный снимок, его герой и экономика заблокированы от ручного редактирования; для полностью ручной работы отключите источник.
